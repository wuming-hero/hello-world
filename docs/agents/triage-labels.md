# Triage 标签

这些 skills 使用五个标准 triage 角色。本文件将这些角色映射到本仓库 issue 跟踪方式中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库跟踪器中的标签 | 含义                             |
| -------------------------- | -------------------- | -------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估该 issue           |
| `needs-info`               | `needs-info`         | 正在等待报告者提供更多信息       |
| `ready-for-agent`          | `ready-for-agent`    | 规格已完整，可交给 AFK agent     |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现                     |
| `wontfix`                  | `wontfix`            | 不会处理                         |

当某个 skill 提到一个角色时（例如“apply the AFK-ready triage label”），使用上表中对应的标签字符串。

如果你实际使用的词汇不同，可以编辑右侧列以匹配你的标签体系。
