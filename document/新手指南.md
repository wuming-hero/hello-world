# 项目新手指南

> 本文档面向第一次接触本仓库的同学，帮助你快速了解项目是什么、代码和文档放在哪里、怎么运行与扩展。读完本文你就能上手。

## 1. 这是什么项目？

**个人 Java 学习与技术笔记仓库**（`hello-world`）。它不是生产服务，而是一个"知识库 + 练习场"：

- **代码**：把工作中遇到的有用、重要的知识点用 Java 示例固化下来（`src/main/java`）
- **笔记**：沉淀了大量中文技术笔记，覆盖 Java 基础、JVM、并发、框架、中间件、数据库、分布式、设计模式、运维、AI 等主题（`document`）
- **测试**：用 JUnit 4 写的各种小实验（`src/test/java`）

仓库作者是一名有丰富后端经验的开发者（曾任菜鸟裹裹项目 PM/服务端研发，做过开放平台、电商退货、支付营销等业务，详见 `document/项目梳理.md`）。

## 2. 环境与技术栈

| 项 | 要求 |
|---|---|
| JDK | **Java 8**（`pom.xml` 指定 `source/target 1.8`，除非明确要求，不要升级） |
| 构建工具 | Maven 3.x |
| 测试框架 | JUnit 4.12 |
| 核心依赖 | Lombok、Guava、Fastjson、Jackson、HttpClient、Log4j2 + SLF4J、Joda-Time、dom4j/jdom2/Jsoup、POI + EasyExcel、Zxing、BouncyCastle（RSA）、Dozer |

依赖版本全部集中在 `pom.xml` 的 `<properties>` 中管理，**不要随意升级已有依赖版本**。

- 新增示例放在**对应主题的包**下新建类，不要混入无关类
- 示例保持小而聚焦
- 除非必要，避免大范围重构

## 8. 常见操作

### 8.1 运行全部测试
```bash
mvn test
```

### 8.2 运行单个测试
```bash
mvn -Dtest=RegexTest test
```

### 8.3 新增一个 Java 示例
1. 找到对应主题的包（如日期相关的放 `com.wuming.date`）
2. 新建一个小的、聚焦的类
3. 如需验证，在 `src/test/java` 新增 JUnit 测试或用 `main` 直接跑

### 8.4 新增一篇技术笔记
1. Markdown 文件放入 `document/` 下对应主题目录（无合适目录可新建）
2. 图片放入 `static/image/` 或 `src/main/resources/static/image/` 下对应主题目录，笔记中用**相对路径**引用
3. 保持现有 Markdown 风格，不要重写大段已有内容

### 8.5 验证变更
- 改了 Java 代码 → 跑相关测试（`mvn test` 或单测）
- 只改了 Markdown → 检查引用路径即可，无需跑 Maven

## 9. 需要遵守的规范

1. **保持 Java 8 兼容性**（除非用户明确要求改 JDK 级别）
2. **依赖版本锁定**：在 `pom.xml` 的 `<properties>` 中管理，不随意升级
3. **包结构**：遵循 `com.wuming` 下按主题组织的结构
4. **不提交** `target/`、IDE 文件等构建产物
5. **文档语言**：技术笔记用中文；个人文档（简历、项目梳理）勿随意修改
